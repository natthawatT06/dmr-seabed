# Source and attribution

Sediment data is provided by Thailand's Department of Mineral Resources (DMR).
The publisher catalogue links to the same ArcGIS service used in this project:

- https://data.dmr.go.th/dataset/seafloor_surficial_sediment
- https://gisportal.dmr.go.th/arcgis/rest/services/ENVI/SEAFLOOR_SURFICIAL_SEDIMENT/MapServer

The catalogue labels the data licence "Creative Commons Attributions" without
specifying a version. Preserve DMR attribution and consult the publisher for
precise reuse terms. A regional subset and processing provenance are included.

Basemap attribution: OpenFreeMap, OpenMapTiles and OpenStreetMap contributors.
Basemap assets are fetched by the browser and are not bundled in this repository.

No general open-source software licence is declared for the project code.
Public repository visibility does not replace the source data's licence.
