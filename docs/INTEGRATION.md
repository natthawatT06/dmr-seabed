# เชื่อมข้อมูลตะกอนกับตัวพยากรณ์ตำแหน่งลูกปู

## สิ่งที่ระบบพยากรณ์ส่งมา

ให้ส่ง **พิกัดปลายทางที่คำนวณแล้ว** เป็น longitude/latitude ใน EPSG:4326
พร้อมรหัสอนุภาค เวลา และระยะเวลาจำลอง หากต้องการประกอบผลที่ 20 วัน ต้องเลือก
frame ของวันที่ 20 จากโมเดลของเพื่อนก่อน ไม่ควรส่ง frame ล่าสุดที่หยุดกลางทาง
แล้วระบุว่าเป็นผลครบ 20 วัน

แนะนำให้เก็บ transport status จากโมเดลเดิม เช่น completed, stranded,
outside-current-grid และ missing-forcing ควบคู่ไปด้วย การพบ polygon DMR
ไม่ได้ทำให้เส้นทางที่จำลองไม่ครบกลายเป็นผลที่ใช้ได้

## การประมวลผล

1. โหลดชุด DMR และสร้าง spatial index ครั้งเดียวต่อ dataset version
2. ตรวจว่าจุดอยู่ในวงข้อมูลหรือไม่
3. ค้นหา polygons ใกล้จุดด้วย STRtree แล้วตรวจ `covers(point)` จริง
4. คืนทุกขอบเขตที่ตรงพิกัด หากมีคนละชนิดตะกอนให้เก็บ `ambiguous`
5. เชื่อมผลตามรหัสอนุภาค โดยเก็บ prediction เดิมและ provenance DMR แยกกัน

ไม่มีการ resample หรือประมาณชนิดตะกอนให้จุดที่ไม่มีข้อมูล

## แนะนำฟิลด์สำหรับเก็บในฐานข้อมูลของเพื่อน

| ฟิลด์ | เหตุผล |
|---|---|
| `simulation_id`, `particle_id` | เชื่อมกลับไปยังผลพยากรณ์ |
| `longitude`, `latitude`, `prediction_time`, `elapsed_days` | พิกัดและเวลาที่นำมาตรวจ |
| `transport_status` | ผลจำลองครบตามเวลาที่ขอหรือไม่ |
| `dmr_status`, `dmr_class_key` | ชนิดตะกอนและกรณีไม่มีข้อมูล |
| `dmr_matches` | ทุก polygon ที่ตรงพิกัดและ native labels |
| `dmr_source_sha256`, `dmr_source_fetched_at` | ระบุข้อมูลที่ใช้ในครั้งนั้น |
| `habitat_suitability` | เก็บ `unknown` จนกว่าจะมีเกณฑ์/หลักฐานอื่น |

สคริปต์ `lookup_points.py` เก็บ record ที่ป้อนมาทั้งหมดใน `prediction` จึงส่ง
`transportStatus` หรือชื่อฟิลด์ของโมเดลเดิมเข้ามาได้โดยไม่สูญหาย แต่สคริปต์ไม่ได้
ตัดสิน transport status ให้ ต้องกรองในระบบของเพื่อน

## การสรุปเป็นสัดส่วน

สามารถสรุปจำนวนอนุภาค `mapped` ในแต่ละชนิดตะกอน โดยรายงาน `unmapped`,
`outside-coverage`, `ambiguous` และเส้นทางที่ไม่ครบแยกกัน

อย่าทิ้งกรณีที่ไม่ทราบออกจากตัวหารโดยไม่รายงาน เพราะจะทำให้สัดส่วนทรายที่แสดง
ดูสูงกว่าผลรวมจริง สัดส่วนปลายทางบนทรายไม่ใช่อัตรารอดของปู และอนุภาคแบบสุ่ม
จำลองก็ไม่ใช่จำนวนปูจริงโดยอัตโนมัติ

## ข้อจำกัดของตำแหน่ง

รูปหลายเหลี่ยมเป็นแผนที่ตะกอนระดับพื้นที่ ขอบอาจไม่ตรงกับชายฝั่งละเอียดของ
basemap หรือแบบจำลอง land mask จุดบนขอบใช้ `covers()` และอาจได้หลาย match
ควรรายงานความไม่แน่นอนของเส้นทางและของแผนที่แยกกัน

ไฟล์ทุกชุดเป็นข้อมูลประกอบจาก DMR; repo นี้ไม่มีข้อมูลภาคสนาม C1 ของเกาะสีชัง
หรือโมเดลการเติบโต/การรอดชีวิต
